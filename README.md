# 読者特典テンプレート集

『はじめてのパートナーAIの使い方 ― Museを常駐させる運用の実践記録』（著者：AI共生ラボ）の読者特典です。
本書で紹介した「型」を、コピーしてそのまま使える形でまとめたものです。自分の言葉に差し替えて使ってください。

## 内容

- appendix_A_memory_template.md ― 付録A 記憶ファイル雛形（空の雛形と記入例／第2章）
- appendix_B_handover_template.md ― 付録B 引き継ぎ文テンプレ（四点セットの型と記入例／第4章）
- appendix_C_job_template.md ― 付録C 定期ジョブ指示文テンプレ（型と記入例／第5章）
- appendix_D_check_sheet.md ― 付録D 検証チェックシート（報告の四点セット記入欄と、合否チェックの作り方／第6章）
- appendix_E_7days_setup.md ― 付録E 最初の7日間セットアップ手順（第1章ほか）
- all_templates.md ― 上記5点を1ファイルにまとめたもの

## 使い方

各ファイルはMarkdown形式です。そのままコピーして、メモ帳やノートアプリ、AIへの指示文に貼って使えます。
まずは付録Eの手順に沿って進めると、本書の仕組みを一週間で一通り体験できます。
